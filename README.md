## 🎯 プロジェクト概要

美容室ウイング R の公式ウェブサイトです。**「老舗の安心感 × モダンな使いやすさ」**をコンセプトに、ワンページ構成で必要な情報をすべて伝達し、5 分以内で予約判断ができるユーザー体験を提供します。

### 主な特徴

- 📱 **モバイルファースト**のレスポンシブ設計
- 🎨 **温かみのある色調**（ベージュ、ブラウン、クリーム系）
- ⚡ **ワンページスクロール**で直感的なナビゲーション
- 🌟 **創業 41 年の実績**と地域密着の価値を表現

## 🚀 開発・実行

### 必要な環境

- Node.js 18.0 以上
- npm / yarn / pnpm

### インストール

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いて確認できます。

### ビルド・デプロイ

```bash
# 本番用ビルド
npm run build

# 本番サーバー起動
npm run start
```

## 🏗️ 技術スタック

### フロントエンド

- **Next.js 14** (App Router) - React フレームワーク
- **TypeScript** - 型安全性
- **Tailwind CSS** - ユーティリティファースト CSS
- **Framer Motion** - スクロールアニメーション
- **React Hook Form** - フォーム管理
- **Lucide React** - アイコンライブラリ

### 開発ツール

- ESLint - コード品質チェック
- PostCSS - CSS 処理
- TypeScript - 型チェック

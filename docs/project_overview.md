# 美容室ウイング R プロジェクト概要

## 📋 プロジェクト基本情報

### サイト概要

- **サイト名**: 美容室ウイング R
- **サロン設立**: 1983 年（41 年の歴史）
- **所在地**: 岐阜市加野
- **特徴**: 3 世代に愛されるファミリーサロン

### 技術スタック

- **フレームワーク**: Next.js 14 (App Router)
- **言語**: TypeScript (strict mode)
- **スタイリング**: Tailwind CSS + カスタムデザインシステム
- **UI**: framer-motion アニメーション
- **フォーム**: React Hook Form + Zod
- **アイコン**: Lucide React
- **CMS**: microCMS（お知らせ・ブログ機能）

## 🎯 プロジェクト目標

### ビジネス目標

- **新規顧客獲得**: 検索エンジンからの集客向上
- **リピート促進**: 既存顧客との関係性強化
- **ブランド価値向上**: 41 年の信頼と現代的なデジタル体験の融合
- **世代横断的な利用**: 10 代～ 70 代まで使いやすい UI/UX

### 技術目標

- **パフォーマンス**: Core Web Vitals 優秀評価
- **アクセシビリティ**: WCAG AA 準拠
- **SEO**: 地域密着型キーワードでの上位表示
- **保守性**: 継続的な機能追加・改善が可能な設計

## 🏗️ サイト構成

### 基本ページ

- **トップページ** (`/`): ヒーロー、特徴、お客様の声、アクセス
- **メニュー・料金** (`/menu`): 全メニューと価格一覧
- **お問い合わせ** (`/contact`): フォーム + 電話・LINE 予約

### 予定機能（設計完了）

- **お知らせ** (`/notices`): 営業情報・キャンペーン情報
- **ブログ** (`/blog`): ヘアケア・美容情報の発信
- **Gallery** (`/gallery`): 店内雰囲気・施術写真
- **Feature 詳細**: ヘッドスパ・縮毛矯正の専門ページ

## 🔧 開発環境

### 必要な環境

- Node.js 18+
- npm または yarn
- Git
- VSCode（推奨）

### 主要コマンド

```bash
# 開発サーバー起動
npm run dev

# ビルド
npm run build

# 型チェック
npm run type-check

# リント
npm run lint
```

### 環境変数

```bash
# 基本設定
NEXT_PUBLIC_BASE_URL=http://localhost:3001

# microCMS（実装時に追加）
MICROCMS_SERVICE_DOMAIN=hair-salon-wingr
MICROCMS_API_KEY=your_api_key_here
```

このマニュアルは、美容室ウイング R のウェブサイトのコンテンツ（お知らせ・ブログ記事）を更新・管理するための操作手順書です。

### 対象者

- 美容室ウイング R のオーナー・スタッフ

- microCMS の管理画面へのアクセス権限

## 📢 お知らせ機能の使い方

### お知らせとは？

営業時間の変更、キャンペーン情報、重要なお知らせなど、短期間で伝えたい情報を投稿する機能です。

### 1. 新しいお知らせを投稿する

#### 手順 1: お知らせ管理画面を開く

1. 管理画面で「お知らせ」をクリック
2. 「新規作成」ボタンをクリック

#### 手順 2: 必須項目を入力

**🔴 必須項目（必ず入力が必要）**

| 項目名       | 説明               | 入力例                                     |
| ------------ | ------------------ | ------------------------------------------ |
| **タイトル** | お知らせのタイトル | 「12 月の営業時間変更のお知らせ」          |
| **内容**     | お知らせの詳細内容 | 詳細説明文（HTML エディタで編集）          |
| **カテゴリ** | お知らせの種類     | お知らせ・キャンペーン・営業時間変更・重要 |
| **公開日時** | いつから表示するか | 2025/01/29 10:00                           |

**⚪ 任意項目（入力しなくても大丈夫）**

| 項目名             | 説明                       | 使用例                           |
| ------------------ | -------------------------- | -------------------------------- |
| **サムネイル画像** | 一覧で表示される画像       | キャンペーンのバナー画像など     |
| **トップ固定**     | 重要なお知らせを上部に固定 | 重要なお知らせの場合のみチェック |

#### 手順 3: カテゴリの選び方

- **お知らせ** 🔵: 一般的な情報（新メニュー導入、スタッフ変更など）
- **キャンペーン** 🟡: 割引・特典情報
- **営業時間変更** 🟠: 営業時間・定休日の変更
- **重要** 🔴: 緊急・重要な情報（臨時休業、重大な変更など）

#### 手順 4: 内容の書き方

```
例：営業時間変更のお知らせ

いつもご来店いただき、ありがとうございます。

12月30日（土）〜1月3日（水）は、年末年始のため下記の通り営業時間を変更させていただきます。

【変更期間】
12月30日（土）〜1月3日（水）

【営業時間】
10:00〜17:00（通常：9:00〜19:00）

ご迷惑をおかけいたしますが、何卒ご理解のほどよろしくお願いいたします。

ご不明な点がございましたら、お気軽にお問い合わせください。
```

#### 手順 5: 保存と公開

1. 「下書き保存」または「公開」を選択

   - **下書き保存**: まだ公開しない（後で編集可能）
   - **公開**: すぐにウェブサイトに表示される

2. 「保存」ボタンをクリック

### 2. 既存のお知らせを編集する

1. 「お知らせ」管理画面を開く
2. 編集したいお知らせのタイトルをクリック
3. 内容を修正
4. 「更新」ボタンをクリック

### 3. お知らせを削除する

1. 「お知らせ」管理画面を開く
2. 削除したいお知らせの右端にある「...」をクリック
3. 「削除」を選択
4. 確認画面で「削除」をクリック

⚠️ **注意**: 削除したお知らせは復元できません

## 📝 ブログ機能の使い方

### ブログとは？

美容・ヘアケアの専門情報、商品紹介、サロンの詳細情報など、お客様にとって価値のある情報を投稿する機能です。

### 1. 新しいブログ記事を投稿する

#### 手順 1: ブログ管理画面を開く

1. 管理画面で「ブログ」をクリック
2. 「新規作成」ボタンをクリック

#### 手順 2: 必須項目を入力

**🔴 必須項目**

| 項目名               | 説明                   | 入力例                                                            |
| -------------------- | ---------------------- | ----------------------------------------------------------------- |
| **記事タイトル**     | ブログ記事のタイトル   | 「冬の乾燥から髪を守る 5 つの方法」                               |
| **記事内容**         | ブログの本文           | 詳細な記事内容（HTML エディタで編集）                             |
| **記事の抜粋**       | 一覧で表示される要約文 | 「冬の乾燥は髪にとって大敵です。この記事では...」（120 文字以内） |
| **アイキャッチ画像** | 記事のメイン画像       | 記事の内容に関連する画像                                          |
| **カテゴリ**         | 記事の分類             | ヘアケア・スタイリング・商品紹介・サロン情報・トレンド            |
| **公開日時**         | 記事の公開日           | 2025/01/29 14:00                                                  |

**⚪ 任意項目**

| 項目名           | 説明                         | 入力例                                                |
| ---------------- | ---------------------------- | ----------------------------------------------------- |
| **タグ**         | 記事のキーワード             | 「冬のケア,乾燥対策,保湿」（カンマ区切り）            |
| **SEO タイトル** | 検索結果で表示されるタイトル | 「冬の髪の乾燥対策｜美容室ウイング R」（60 文字以内） |
| **SEO 説明文**   | 検索結果で表示される説明文   | より詳細な説明（160 文字以内）                        |

#### 手順 3: カテゴリの選び方

- **ヘアケア** 🟢: 髪や頭皮のケア方法
- **スタイリング** 🟣: ヘアスタイルやセット方法
- **商品紹介** 🔵: おすすめ商品・新商品の紹介
- **サロン情報** 🟠: サロンの設備・サービス・スタッフ紹介
- **トレンド** 🟡: 最新のヘアトレンド・流行スタイル

#### 手順 4: 良いブログ記事の書き方

**記事構成の例:**

```
# 冬の乾燥から髪を守る5つの方法

冬になると「髪がパサパサする」「静電気がひどい」といったお悩みを多く伺います。
今回は、自宅でできる簡単な乾燥対策をご紹介します。

## 1. シャンプーの見直し

冬場は洗浄力の穏やかなシャンプーに変更することをおすすめします。
...

## 2. トリートメントの使い方

...

## まとめ

冬の髪の乾燥対策は、日々のケアの積み重ねが重要です。
ご不明な点がございましたら、お気軽にサロンでご相談ください。
```

**記事を書く時のポイント:**

✅ **良い例**

- 具体的で実用的な情報
- お客様の悩みに寄り添った内容
- 専門知識をわかりやすく説明
- 定期的な更新（月 2-3 回程度）

❌ **避けるべき内容**

- 他店の批判的な内容
- 医学的な断定的表現
- 商品の過度な宣伝
- プライベートすぎる内容

### 2. 画像の選び方・アップロード方法

#### 画像の要件

- **推奨サイズ**: 横 800px 以上
- **ファイル形式**: JPG、PNG
- **ファイルサイズ**: 1MB 以下

#### アップロード手順

1. 「アイキャッチ画像」欄の「ファイルを選択」をクリック
2. パソコンから画像を選択
3. 「アップロード」をクリック
4. 画像の代替テキスト（ALT）を入力
   - 例：「ヘアトリートメントを塗布している様子」

#### 使用できる画像

- ✅ 自店で撮影した写真
- ✅ 著作権フリーの素材サイトの画像
- ✅ 商品メーカーから提供された画像

## 🔧 よくある操作・トラブル解決

### 1. 文字装飾の方法

#### 太字にする

1. 太字にしたい文字を選択
2. ツールバーの「B」ボタンをクリック

#### 見出しを作る

1. 見出しにしたい行を選択
2. ツールバーの「見出し」から「見出し 2」「見出し 3」を選択

#### リンクを張る

1. リンクしたい文字を選択
2. ツールバーの「🔗」ボタンをクリック
3. URL を入力して「OK」

### 2. 画像の挿入

1. 画像を挿入したい位置にカーソルを置く
2. ツールバーの「画像」ボタンをクリック
3. 画像をアップロードまたは選択

### 3. トラブルシューティング

#### Q: 保存ボタンを押してもエラーが出る

**A:** 必須項目がすべて入力されているか確認してください

- タイトル
- 内容
- カテゴリ
- 公開日時

#### Q: 画像がアップロードできない

**A:** 以下を確認してください

- ファイルサイズが 1MB 以下か
- ファイル形式が JPG、PNG か
- インターネット接続は安定しているか

#### Q: 投稿した内容がサイトに反映されない

**A:** 以下を確認してください

- 「公開」を選択しているか（「下書き」のままではない）
- 公開日時が現在より前に設定されているか
- ブラウザの更新（F5 キーまたは再読み込み）を試す

#### Q: 誤って削除してしまった

**A:** 残念ながら削除されたコンテンツは復元できません。重要なコンテンツは削除前に十分確認してください。
